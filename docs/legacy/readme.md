# Ogarniacz SM (MVP)
- Edit `config.json` to add/remove tiles.
- The app auto-refreshes every `auto_refresh_seconds`.
- Click **Refresh** to force reload instantly.

## Run (dev)
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py

## Build (optional later)
Use PyInstaller when ready to distribute.
