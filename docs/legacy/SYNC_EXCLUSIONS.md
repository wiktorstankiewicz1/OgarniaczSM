# Synology Drive Sync Exclusions

## Problem
The build process creates thousands of files (PySide6 libraries, build artifacts) that don't need to be synced and can cause Synology Drive to crash or slow down.

## Solution: Exclude Build Directories and PROD

### Files/Folders to Exclude from Sync:
- **`PROD/`** - Production releases (accessible via network share Y:\, no sync needed)
- `dist/` - Build output (can be regenerated)
- `build/` - Build artifacts (can be regenerated)
- `*.spec` - PyInstaller spec files (auto-generated)
- `.venv/` - Virtual environment (if using one)
- `__pycache__/` - Python cache files

### Why Exclude PROD?
- `PROD/` contains PySide6 (619.73 MB, 3713 files) that's identical across versions
- Other computers access `PROD/` directly via the network share (`Y:\`)
- Auto-update reads from the network path - sync is NOT needed
- Excluding PROD prevents Synology Drive from syncing thousands of files

### How to Exclude in Synology Drive:

1. **Open Synology Drive Client**
2. **Go to Settings → Advanced → Selective Sync**
3. **Add exclusion rules:**
   - `PROD/` ⭐ **IMPORTANT: Exclude this to prevent sync crashes!**
   - `dist/`
   - `build/`
   - `*.spec`
   - `.venv/`
   - `__pycache__/`

Or use pattern matching:
- `**/PROD/**` ⭐ **Most important exclusion!**
- `**/dist/**`
- `**/build/**`
- `**/*.spec`
- `**/.venv/**`
- `**/__pycache__/**`

### Why This is Safe:

- **`dist/` and `build/`** are build artifacts - they're regenerated every time you run `GENERATE_OGARNIACZ_EXE.py`
- **`.spec` files** are auto-generated by PyInstaller
- **`.venv/`** can be recreated with `pip install -r requirements.txt`
- **`__pycache__/`** is Python's cache - automatically regenerated

### What SHOULD Be Synced:

✅ Source code (`.py` files)
✅ Configuration files (`config.json`, `version.txt`, etc.)
✅ Resources (`icons/`, `icon.ico`)
✅ Build scripts (`GENERATE_*.py`, `build_installer.py`, etc.)
✅ Documentation (`*.md`, `*.txt`)
✅ `requirements.txt`
✅ `.gitignore`

---

## Alternative: Build to Local Directory

If you can't exclude directories in Synology Drive, you could modify the build scripts to output to a local directory that's not part of the sync, but this is more complex and less recommended.
